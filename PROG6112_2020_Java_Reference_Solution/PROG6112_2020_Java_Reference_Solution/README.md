# PROG6112 2020 – Java Reference Solutions

This ZIP contains three separate Java 17 Maven projects matching the uploaded 2020 paper:

1. **Q1_PrinterCartridgeUsage** – Swing GUI for printer/year selection, selected-year
   cartridge usage, and the three-year total report.
2. **Q2_WordTranslations** – one English-word array and a 2D array for Dutch, French
   and Italian translations.
3. **Q3_ProductTracker** – Swing GUI to save products to `Products.txt`, display all
   saved records, and search by product ID.

## Running
Open each question folder separately as a Maven project in IntelliJ IDEA or NetBeans.
Run the main class shown in each question README. For Q3, keep `Products.txt` in the
application working directory.

The sample product records are reproduced from page 10 of the exam. JUnit 5 tests
are included. Main Java source files were compiled with `javac`; the JUnit tests have
not been run in this environment.
