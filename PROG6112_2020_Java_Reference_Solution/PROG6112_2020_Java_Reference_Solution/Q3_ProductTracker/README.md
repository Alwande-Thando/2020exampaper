# Question 3 – Product Tracker

Swing GUI with three product text fields, a non-editable text area, Submit and Search
buttons. Product records are saved sequentially in `Products.txt` as three lines per
record (ID, name, price). Existing products load into the text area at startup and the
list refreshes after a new product is saved. Search prompts for a product ID and
displays the matching name and price.

The included `Products.txt` reproduces the sample records shown in the exam:
10111 Nike Tennis Shoes 950; 10112 Puma Tennis Shoes 750; 10113 Addidas Tennis Shoes 825.
